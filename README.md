# Проект "Банковский виджет"

### Описание
Проект "Банковский виджет" - Это виджет банковских опираций клиента.
Ращраьатываеться для учебных целей.
## Задачи
Задание
Проект развивается, и источником данных о финансовых транзакциях теперь может быть не только JSON-файл, 
но и CSV- или XLSX-файл. Благодаря знаниям о библиотеке 
pandas
 наконец можно реализовать поддержку новых форматов данных.

Скачайте файлы transactions.csv и transactions_excel.xlsx для работы над задачами.

Задачи
 Реализовать считывание финансовых операций из CSV- и XLSX-файлов.
* Дополнительное задание
Типизируйте написанный код и добейтесь того, чтобы 
mypy
 при запуске не выдавал ошибок.
 Напишите тесты для новых функций.
Дополнительное задание, помеченное звездочкой, желательно, но не обязательно выполнять.
